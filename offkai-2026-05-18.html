— 「許可していい？」現象 から虎の巻が育った日

📅 2026-05-18（月）朝 👥 参加者 8名 📍 オンライン ⏱ 約 2時間 🎯 初心者〜中級者 向け

📝 この日の雰囲気

このオフ会の特徴は「参加者の多くがすでにダウンロード済み」だったこと。4月開催の初心者オフ会と比べて、明らかに 層が一段進んだ 感覚があった。だから「インストール手順」より、「許可ダイアログにどう対処するか」「魔法の呪文ってどこにある？」「作業フォルダって何？」みたいな、触り始めた人の生の壁 が次々と出てきた回になった。

この回で繰り返し出てきた質問が、後日 虎の巻FAQ昇格 のトリガーになっている。「現場の声を集める＝虎の巻が育つ」を体現した一回。

🎬 この日やったこと

  • Claude Code とブラウザ版Claude（チャット）の見分け方
  • Claude Code デスクトップアプリの起動・基本操作
  • Chrome拡張機能でのSNSフォロー自動操作デモ
  • 魔法の呪文（CLAUDE.md）の設定（学長マガジン由来）
  • 旅行プランLPの生成デモ
  • 育成ゲーム論：「パソコン内に情報を蓄積するほど精度が上がる」
  • 各参加者の業務文脈（介護記録／英語授業プリント／SNS運用／YouTube配信作業）への活用イメージ広げ

🙋 この日出た質問・困りごと

※ 個人を特定できない形に加工して掲載。原文は内部Vaultにのみ保存。

権限ダイアログ最頻出

「許可していいのか分からない」「永遠にループから抜けられない」「勝手に課金されない？」

このカテゴリだけで 5回以上 別々の参加者から 出た。Claude Codeを触り始めた人の 最大の壁。
現場の回答：「学長と同じく自動モード設定でOK」「決済は勝手にされない」「中身はClaude本人に聞けば教えてくれる」。

▶ 虎の巻FAQ-05に該当するが、本編から見つけにくい状態だったと判明 → 独立章への格上げ要件 として整理
魔法の呪文

「魔法の呪文どこ？」「これ何のためのもの？」

主催者本人がライブで「魔法の呪文どこだ…」と 3回繰り返して画面内を探した。これは ナビゲーションが弱い ことの強い証拠。
現場の説明：「学長マガジン同内容」「ニューセッションに貼り付けるだけ」「Claude本人に中身を聞けばOK」「危なくないようにする憲法みたいなもの」。

▶ トップから1クリックで呪文ページへ飛ぶボタン 追加 が改修要件として確定
作業フォルダ

「フォルダを見たら今日やったことが分かる、の意味が分からない」

初心者の素直すぎる質問。「箱」「引っ越し」「成果物保管」の比喩で説明したが、ここはまだ 体感が追いつかない ポイントとして残った。

▶ 虎の巻に「フォルダ概念のビジュアル説明ページ」追加候補
アプリ判別

「ダウンロードしたつもりがブラウザ版だった」「Claude Codeってどれ？」

意外なつまずき。「Claude」と「Claude Code」と「Claude in Chrome」の 見分けが付かない。
現場の解説：「サイドバーで見分ける」「アプリだと思ったらブラウザ版だった現象は頻出」。

▶ スクショ付き判別ガイド を虎の巻冒頭に置く案
課金

「アプリ版じゃないと使えない？」「Proプラン必須？」「月額に変える？」

2名がここで詰まった。"課金前提" の章が必要 と判明（無料プランでは制約大）。

▶ 2026-05-21 commit df627a9 で「無料プラン不可を明記」修正済み（実装済み）
スキル

「学長ライブのYouTube動画をどうやって自動で認識してるんですか？」

主催者が「スキル」と回答するも、当日は深掘りせず後送り。「スキル＝ショートカット」入門ページ が虎の巻に欲しい、と整理された。

🎤 印象的なシーン

⏰ 開始40分頃 — 許可ダイアログ祭りの中で
「もう許可して、どんどんどんどん許可を教えてください。」
参加者から許可ダイアログが頻発した瞬間、おけもんが思わず言ったセリフ。このオフ会で「許可ダイアログ問題」が虎の巻最大の課題と判明した瞬間。
⏰ 開始1時間18分頃 — 寝てる間にやってくれる？
参加者「寝てる間にやってくれるというのは、パソコンとか閉じたとしても動いてくれるんですか？」
おけもん「基本的には開いてないとダメです。…僕は何回もやってるんで、これは別にいちいち許可しなくても大丈夫だよねってわかってるから、もうそのままやってねっていうふうなモードにしてます」
参加者「いちいち聞くなって思わずに」（笑）
この日一番場が和んだやり取り。「慣れたら自動モード」という現場の知恵が共有された瞬間。
⏰ 開始1時間45分頃 — 結論ボックスが必要
参加者「これって常に許可でいいんですか？」
おけもん「常に許可でいいですね。少なくとも今回のシーンより変なことはしないんで、せいぜいホームページの情報取ってきていいですかとか、リサーチしに行っていいですか、みたいな許可だと思うんで。問題ないです。」
この主催者の即答が、虎の巻FAQに 「結論ボックス」 として転載される必要があると確定した瞬間。

🌱 この日からの学び・気づき

  • 初心者は「許可ダイアログ」が想像以上の壁。Yes/No判断できない・無限ループ・課金不安の3パターンに整理できる
  • 魔法の呪文への動線がトップから弱い。主催者本人が迷子になるレベル＝完全にナビが足りない
  • 「Claude」「Claude Code」「Claude in Chrome」の判別が初心者にとって死活問題
  • "課金前提" を最初に伝えるのが優しさ（無料で詰まる人を救う）
  • 育成ゲーム論はめちゃくちゃ刺さる。「情報を蓄積するほど精度が上がる」のメタファーが分かりやすい
